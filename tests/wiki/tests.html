E2E WebSocket 测试

完整写作流程端到端验证 — 三种模式覆盖
🚀 Auto 模式
全自动写作流程：意图识别 → 检索 → 写作 → 自检 → 修正。
# 默认 auto 模式
node e2e-test.mjs

# 自定义消息 + writing 模式
node e2e-test.mjs "你的消息" --mode writing
📋 Guided 模式
引导式写作：提纲确认/编辑/重做 → 流式写作。测试暂停/恢复。
# 提纲确认 + 暂停/恢复
node e2e-guided-test.mjs

# 测试提纲重做
node e2e-guided-test.mjs --regenerate
💡 Writing 模式
深度写作：启用 reasoning_content 推理链可视化。
# 启用思维链可视化
node e2e-test.mjs --mode writing

WebSocket 事件协议

客户端 → 服务端:
  { "type": "agent.start",   "payload": { "message": "...", "style": "yinyue", "mode": "guided" } }
  { "type": "agent.pause",   "payload": { "traceId": "..." } }
  { "type": "agent.resume",  "payload": { "traceId": "..." } }
  { "type": "agent.cancel",  "payload": { "traceId": "..." } }
  { "type": "agent.confirm", "payload": { "traceId": "...", "step": "outline", "data": { ... } } }

服务端 → 客户端:
  { "type": "agent.step.start",    "payload": { "traceId": "...", "step": "search" } }
  { "type": "agent.step.complete", "payload": { "traceId": "...", "step": "search", "duration_ms": 5647 } }
  { "type": "agent.stream",        "payload": { "traceId": "...", "delta": "文章片段..." } }
  { "type": "agent.reasoning",     "payload": { "traceId": "...", "delta": "思考过程..." } }
  { "type": "agent.completed",     "payload": { "traceId": "...", "article": "...", "review": {...} } }
  { "type": "agent.error",         "payload": { "traceId": "...", "code": "timeout", "message": "..." } }

场景描述测试消息对比维度
