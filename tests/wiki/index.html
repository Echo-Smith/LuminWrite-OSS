核心写作流程

从用户输入到成稿的完整管道
# 用户输入 → 意图路由 → 双引擎执行 → 成稿输出

用户输入
    │
    ▼
Harness 单层 LLM 编排 — 意图路由(规则,毫秒级) → 工具选择 → Agent Loop(max 12轮)
    │
    ├─ chat → ChatStep (注入历史+实体+工作记忆 → LLM 流式回复)
    │
    ▼ (writing)
AgentEngine 状态机管道
    记忆 → 意图 → 检索计划 → 多源搜索(知乎/IMA/Tavily/腾讯/微博)
    → 相关性过滤+去重 → 素材压缩 → 提纲(Guided) → 风格化写作(流式)
    → 写后自检 → 自动修正 → 记忆提取 → 存储 → 输出成稿 + Trace 记录

双引擎设计

Pipeline 与 Harness 按场景智能切换
⚙️ Pipeline (AgentEngine)
状态机管道模式：16 个 Step 顺序执行，每步可暂停/恢复，6 层退出保护。适合确定性流程。
  • 步骤固定：记忆→意图→检索→过滤→压缩→提纲→写作→自检→修正
  • 每步独立超时 + 优雅降级
  • 关键步骤失败终止，非关键步骤失败跳过
  • Token 预算 30 万 + 断路器（3 次连续失败）
🧠 Harness (LLM Agent Loop)
单层 LLM 编排模式：LLM 自主决定调用工具，最多 12 轮迭代。会话状态跨轮保留。
  • 工具粒度细：search_web / search_knowledge / read_source / write_article / review_article
  • 意图判定走规则（毫秒级），不走 LLM
  • LLM 自主决定何时搜索、何时写作、何时修正
  • 不存在外层 ReAct + 内层 agent loop 嵌套
