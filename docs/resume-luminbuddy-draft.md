## 笔润智谈 LuminBuddy — AI 写作 Agent 产品

**2026.03 — 至今 · 独立完成**

面向中文专栏作者的 AI 写作工作台。作者写稿时不只缺一篇初稿——资料核验、表达同质化、个人视角丢失和返工协作才是真正的瓶颈。笔润智谈把写作拆解为意图识别、多源素材检索、提纲确认、风格化写作和写后审校，让 AI 负责素材搜集和结构规划，把提纲确认和风格调整等高代价决策点交还用户。

**产品决策与迭代**

- 设计 Guided（引导）与 Auto（自动）双模式。Auto 模式由 Agent 自主完成全流程；Guided 模式在提纲生成后暂停，等用户确认或编辑后再成稿，最多支持五次重做。连续 2 周对比 77 组真实任务样本，Guided 完成率相对 Auto 提升 15%，平均多耗时 40 秒，但用户后续修改对话减少 7.4 次——用 40 秒的确认换取更少的返工。评测结果决定保留 Guided 模式和来源证据闸门。

- 用户反馈"逻辑更强但格式趋同"后，调整写作规范并禁用模板化句式。面对标题伦理和个人视角的分歧，没有把一次意见写入全局 Prompt，而是设计了按用户、来源和范围生效的个性化记忆系统（四层：硬偏好 / 行为模式 / 反馈信号 / 实体网络），让修改只影响指定范围，不影响其他作者。

- 把固定 Pipeline 的 10+ 次独立 LLM 调用收敛为一次持续会话，LLM 自主决定何时搜索、何时写作、何时修正，首字延迟从 30–60 秒降至 3–5 秒。会话状态跨轮持久化，文章、素材和搜索记录在同一对话内累积复用。

- 为 LLM 持续会话注册了 11 个写作工具（搜索、知识库检索、提纲生成、流式写作、质量评审、定向修改、事实核查等），LLM 根据任务自主调用。`retrieve_context` 工具让 LLM 按需查询文章片段、记忆和风格配置，System Prompt 从 3000+ tokens 精简到 500–800 tokens。

- 设计研究 → 写作 → 审校三角色 Agent 编排系统，每个角色有独立工具集。审校 Agent 根据信源数量、信息缺口和验证声明自动评分——达标自动推进，一般问题退回写作 Agent，严重问题升级人工处理。

- 构建 A/B 评测框架和评测中心，支持数据集管理、冻结候选、Shadow Run 和人工评审。风格配置变更自动触发评测，评测结果决定保留、关闭或暂缓发布。

**验证结果**

- 截至 2026 年 8 月，14 名作者使用产品，其中 10 名作者累计完成 37 篇在各自媒体栏目上刊发的稿件，单个用户最高使用 20 余次。早期累计覆盖 200+ 体验用户。

- 评测结果已驱动多项产品决策：保留来源证据闸门、关闭默认风格 Memory、将请求失败和修改负担回流为异常监控和迭代队列。正式归一化 Benchmark 仍在进行中。

**技术栈**：Go / React 19 + TypeScript / PostgreSQL 17 + pgvector / DeepSeek API
