# SenseNova 验收请求节流

用户已授权继续真实模型测试。当前整条 HTTP 链路在短时间发出 baseline/candidate 及多步骤调用，触发接口 RPM 限额。

采用客户端可选 RoundTripper 节流：覆盖该客户端的所有流式、非流式、重试与 Responses 请求；默认关闭；等待服从请求 context；取消不提前占用后续时间槽。本轮只在测试中通过 TASK13_LLM_MIN_REQUEST_INTERVAL_MS 设置，不修改生产环境。

不改变质量断言、线上策略、节点超时或模型响应；若低 RPM 无法在现有预算内完成，保留失败作为待处理结果。单客户端节流不等于同一账户跨客户端、跨实例的全局配额控制。

验证：并发请求间距、取消等待不访问网络、不影响后续请求、流式与非流式共用节流，以及真实 HTTP 完整运行。
